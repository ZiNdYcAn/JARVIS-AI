## 2. Description and Scope of the Software

JARVIS is an autonomous, local-first artificial intelligence assistant that operates directly on your personal computer. The Software performs multi-modal computer automation, including:

* **Spoken Voice Interaction:** Continuous real-time voice conversations, streaming speech output, and wake-phrase monitoring.
* **Computer Screen & Visual Perception:** Live screen analysis, optical visual inspection of open windows and active user interfaces, and automated mouse and keyboard simulation.
* **Camera & Facial Perception:** Optional webcam video capture for user presence detection, attention monitoring, and facial identity verification.
* **24/7 Background Service & Scheduling:** Persistent background execution enabling automated tasks, time-triggered reminders, and autonomous checks when the visual desktop overlay is closed.
* **Two-Way Smartphone Calling & Remote View:** Direct voice communication between your PC and your registered mobile phone, including outbound phone calls placed by JARVIS, incoming voice calls from the user, and remote desktop screen streaming.
* **Email & Third-Party Service Automation:** Inbox scanning, email summarization, draft creation, and message dispatching via user-authenticated accounts.
* **Hardware & Operating System Telemetry:** System audio volume, display brightness, Wi-Fi networks, Bluetooth device pairing, application window states, and local file operations.
* **Persistent Memory & Context Consolidation:** Storage of session logs, user preferences, personal information, and AI-driven memory compression.
